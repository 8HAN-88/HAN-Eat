# 🧪 Тестирование Ботов и Мини-приложений (MVP)

## Предварительные требования

1. **Backend миграция** — выполни SQL-скрипт:
   ```bash
   psql $DATABASE_URL -f backend/migrations/add_bot_support.sql
   ```
   Или примени через Alembic (если настроен).

2. **Запущен backend** (FastAPI) с новыми эндпоинтами.

3. **Flutter app** собран с `--dart-define=APP_VARIANT=social` (HanWe).

---

## 1. Мини-приложения (каталог)

### Проверка через вкладку «Мини-приложения»
1. Открой HanWe
2. Перейди на вкладку **«Мини-приложения»** (третья внизу)
3. Должен открыться каталог с карточками:
   - Калькулятор калорий
   - Погода
   - Рецепты по фото
   - и т.д.
4. Тапни на **«Калькулятор калорий»**
5. Должен открыться WebView с интерактивным калькулятором
6. Введи вес/рост/возраст → нажми «Рассчитать»
7. Должен появиться SnackBar с `sendData` (демо)

### Проверка через Attach Menu (в чате)
1. Открой любой чат
2. Нажми кнопку **«+»** (вложение)
3. В dock-е должна появиться кнопка **«Мини-приложения»**
4. Тапни — откроется тот же каталог

---

## 2. Боты (BotFather)

### Создание бота
1. Перейди в **Профиль → Мои боты** (или через поиск «Боты»)
2. Нажми **«Создать бота»**
3. Введи:
   - Имя: `Погода`
   - Username: `weather_demo_bot`
   - Описание (опционально)
4. Нажми «Создать»
5. **Сразу скопируй токен** из SnackBar (он показывается один раз!)

### Просмотр и управление ботом
1. В списке «Мои боты» тапни на созданного бота
2. Должен открыться `BotDetailScreen`:
   - Показ токена (скрыт)
   - Поле Webhook URL
   - Список команд (пока пусто)
   - Кнопка «Добавить команду»
   - Кнопка «Добавить в чат / канал»

### Добавление команд
1. В `BotDetailScreen` нажми **«Добавить команду»**
2. Введи:
   - Команда: `weather`
   - Описание: `Показать погоду в городе`
3. Добавь ещё 1–2 команды
4. Убедись, что они появились в списке и можно удалить

### Добавление бота в чат
1. В `BotDetailScreen` нажми **«Добавить в чат / канал»**
2. Выбери любой свой чат (в демо — просто нажми «Добавить»)
3. Бот должен появиться в участниках чата

### Общение с ботом
1. Открой чат, куда добавил бота
2. Напиши `/start`
3. Бот должен ответить приветствием (или `bot_short_description`)
4. Напиши `/help`
5. Бот должен показать список твоих команд
6. Напиши `/weather`
7. Бот должен ответить описанием команды

### Inline Mode (`@bot query`)
1. В **любом** чате (даже без бота) напиши:
   ```
   @weather_demo_bot погода
   ```
2. При отправке должен открыться bottom sheet с результатами
3. Выбери команду → она отправится в чат

---

## 3. Проверка Webhook (опционально)

1. В `BotDetailScreen` введи любой URL (например, `https://your-server.com/webhook`)
2. Нажми «Сохранить webhook»
3. Убедись, что SnackBar показал «Webhook сохранён»

---

## 4. Известные ограничения MVP

- Токен показывается только при создании (не хранится в `BotResponse`)
- Inline Mode работает только при **отправке** сообщения `@bot query` (не при вводе)
- Webhook сохраняется, но не используется встроенным обработчиком (для внешних серверов)
- Мини-приложения работают только в WebView (не в iframe sandbox)
