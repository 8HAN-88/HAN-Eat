# Отчёт по дисциплине «Информатика»

Готовый отчёт с титульным листом и развёрнутыми ответами на контрольные вопросы курса.

## Файлы

- [Otchet_po_informatike.docx](Otchet_po_informatike.docx) — редактируемый документ (Word / LibreOffice)
- [Otchet_po_informatike.pdf](Otchet_po_informatike.pdf) — версия для печати и сдачи

## Титульный лист

На титуле указаны два исполнителя:

- Хафиев Айрат Нариманович
- Кокорев Максим Евгеньевич

Пустые строки оставлены для названия вуза, группы, направления подготовки, ФИО преподавателя, оценки и даты.

## Содержание

32 контрольных вопроса по семи разделам:

1. Основы информатики и информация  
2. Представление данных в компьютере  
3. Аппаратное и программное обеспечение  
4. Алгоритмизация и программирование  
5. Компьютерные сети и Интернет  
6. Базы данных и информационные системы  
7. Информационная безопасность  

Оформление: ГОСТ 7.32–2017, шрифт Times New Roman 14 пт, интервал 1,5, поля 30 / 15 / 20 / 20 мм.

## Как пересобрать

```bash
python3 docs/otchet-informatika/generate_report.py
libreoffice --headless --convert-to pdf docs/otchet-informatika/Otchet_po_informatike.docx
```
